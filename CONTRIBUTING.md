# Contributing

Спасибо за интерес к проекту!  
Чтобы участие было простым и понятным, следуйте нескольким базовым правилам:

## **Работа через issues**  
- перед началом изменений создайте issue, описав проблему или идею.  
- закрываются задачи только **через pull‑request**: в PR указывайте, какой issue решаете (`Closes #123`).

## **Ветки**  
- для каждой фичи/исправления создавайте отдельную временную ветку от `main` (например, `feature/text‑embedding` или `fix/pdf‑chunking`).  
- перед открытием PR **синхронизируйте ветку с `main`**, подтяните последние коммиты (`git merge main` или `git rebase main`).

## **Код-стайл и тесты**  
- старайтесь придерживаться существующего стиля кода; 
Перед коммитом обязательно проверяйте код линтером: 

```sh
ruff check
``` 
Также рекомендуется установить форматтер, например `black` в редакторе `vscode`.  

- добавляйте/обновляйте юнит‑тесты, если меняете поведение.

## **Ревью**  
  - PR проходит ревью другим участником; 
  - после одобрения мержится в `main`.

Это минимальный набор – по мере роста проекта правила могут дополняться.  
Спасибо за вклад!

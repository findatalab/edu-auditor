# edu-auditor
Система аудита учебных материалов с использованием современных методов и подходов - RAG, LLM
## Usage
1. Создать питоновское окружение
```bash
python3.14 -m venv .venv
```
Активировать его и установить пакеты из requirements.txt    
2. Создать папку DataDocs    
3. В файле archive_feathcer.py поменять save_path переменную на абсолютный путь к папке DataDocs (этот файл устанавливает некторое количество статей из arxiv)    
4. Запустить файл arxhive_fethcer.py (должны скачаться статьи в папку DataDocs)    
5. Далее нужно перейти к файлу vector_database_fill.py, в нем нужно настроить ссылку на локальную postgres базу данных     
6. В этом же файле в методе load_and_save_database установаить аргументы folder_path на папку с статьями и save_to на арбитрарный путь куда вы хотите сохранить векторную базу данных     
7. Запустите vector_database_fill.py (Этот файл чанкирует пдфки, загружает чанки в postgres и одновременно векторизует их в векторную базу данных) Это может занять некоторое время.    
8. Перейти в modelAPI.py. Тут нужно иметь ключ авторизации загруженный в ваши системные переменные. Его можно достать тут: https://developers.sber.ru/portal/products/gigachat-api    
9. Запустить файл modelAPI.py выбрав удобный для вас порт    
10. Перейти в realtional_database.py. Настроить загрузку postgres и векторной баз данных. Запустить на удобном порте.     
11. Перейти в frontend и запустить на streamlit сервере.    
12. Убедитесь что все выбранные порты на backend и frontend правильно связаны http протоколами.
